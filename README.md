# PatioTime Restaurant Website

PatioTime is a restaurant website project built with HTML, CSS, PHP, PostgreSQL/Supabase, and XAMPP.

## Features

- Home page with restaurant information
- About Us page
- Contact page with contact form
- Table reservation form
- Admin login system
- Admin panel for viewing contact messages and reservations
- Data stored in PostgreSQL/Supabase database

## Technologies Used

- HTML
- CSS
- PHP
- PostgreSQL / Supabase
- XAMPP
- GitHub
